# 合映

一个适配 iPhone 的合照接力网站。上传一张原片，领取当前版本，在醒图里修好自己的部分，再回传交给下一位。原片和每一棒的文件都可单独下载。首页的「试用示例」可以用内置合照完整体验流程。

## 私人预览

当前托管站点仅限拥有者登录。接力链接可在自己已登录的设备上打开。首次试用请选择「试用示例」，填写称呼、建立接力，再点「接过这一棒」。

## 本地开发

需要 Node.js 22 或更新版本，无需安装第三方包。在项目目录运行以下命令。

```sh
node server/local.mjs
```

在当前电脑打开 http://127.0.0.1:4173 。本机预览将图片和版本清单保存到忽略提交的 `.data/`，使用单个 Node 进程。生产版本在 Worker 中运行，通过 R2 持久化。

```sh
node --test tests/relay.test.mjs
node scripts/build.mjs
node scripts/validate-artifact.mjs
```

## 照片如何传递

- 每场接力对应一张合照，支持最大 24 MiB 的 JPG、PNG、HEIC、HEIF 或 WebP 静态文件。上传时保留所选文件的字节并记录 SHA-256。文件选择器可能提供相册导出的版本；需要相机文件时，可先导出未修改的原片到「文件」，再上传。
- 同一时间由一位参与者持棒。回传或让棒后即可继续接力。持棒两小时后自动释放。服务器校验持棒者和基础版本，通过条件写入避免同时更新互相覆盖。
- 在支持文件分享的浏览器中，先准备好文件再由用户点击打开系统分享面板。醒图可用时从列表选择，也可以先存储图像，再在醒图中导入。醒图导出和微信发布时使用的画质由各自应用控制。
- 邀请链接包含随机房间标识。托管站点另外受拥有者访问权限保护。浏览器本地仅保存最近访问、称呼和随机参与者凭据。更换浏览器后可用链接找回房间。
- 随附示例为内置 ImageGen 生成的虚构合照，文件位于 `public/coast.jpg`。图像提示词见 `public/coast-prompt.txt`。
